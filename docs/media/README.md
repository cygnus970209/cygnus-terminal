# Documentation screenshots

These PNGs were captured from the current Cygnus UI at 1280 × 900 with synthetic IPC fixtures. No real hosts, passwords, tokens, or personal file listings are shown. Terminal output is illustrative, not a performance measurement.

- `connections.png`: saved SSH, Telnet, and Serial profiles.
- `workspace.png`: terminal, server tools, and the SFTP entry point.
- `vault.png`: example credential metadata and server mappings; no secret values.
- `sftp.png`: local/remote file panels and transfer actions.
